# Lead and Client Operations Dashboard

## Overview
This project is a Power BI dashboard built as the reporting and visibility layer on top of two earlier workflow projects:
- AI-assisted lead management and follow-up workflow
- Client onboarding automation workflow

The dashboard was designed to create better visibility into how those workflows were performing and where operational attention was needed.

## Problem
Running workflows is useful, but without reporting and visibility, it becomes difficult to monitor status movement, follow-up workload, onboarding progress, override cases, and bottlenecks across the process.

## Solution
I built a 4-page operations dashboard in Power BI using cleaned reporting layers from Google Sheets.

The dashboard was designed to track:
- lead status
- follow-up workload
- onboarding stages
- action-needed cases
- override cases
- operational bottlenecks

## Tools Used
- Power BI
- Google Sheets

## Dashboard Structure
The project was structured into 4 pages:

1. Executive Overview  
   High-level operational view across both workflow systems.

2. Lead Funnel & Follow-Up  
   Tracks lead movement, follow-up workload, and override cases.

3. Onboarding Stages  
   Tracks onboarding progress, pending information, kickoff readiness, and completion.

4. Action Needed / Bottlenecks  
   Highlights delayed cases, pending actions, and operational bottlenecks.

## Main Work Done
A major part of the project was not just the dashboard visuals, but cleaning and structuring the reporting layer before building it.

This included:
- separating lead workflow data and onboarding workflow data into clean reporting tabs
- fixing date formatting issues
- correcting column mismatch issues
- importing both reporting layers into Power BI
- building and polishing the dashboard page by page
